Shortcuts, and what to do when sound or notifications are blocked
  • Space starts or pauses while the page has focus, R resets. When a button has focus, Space activates that button, as usual.
  • No sound? Chrome refuses to play any audio until the page has been clicked, so press Test chime once. If it stays silent, open the padlock in the address bar → Site settings → Sound → Allow, make sure the tab is not muted, and check the system volume.
  • No notification? Allow them when Chrome asks, or set Notifications to Allow in the same Site settings panel. Without notifications the tab title counts down and switches to Time is up!, so the end of a run is visible from another tab in the same window.
  • Countdown caught up when you came back? Chrome throttles JavaScript timers in hidden tabs to once a second, and to once a minute after five minutes hidden, so the on-screen refresh can lag. The countdown is recalculated from the clock on every tick and the chime is armed once, in advance, on the audio clock, so the time shown is exact the moment you look at it and the sound still rings on time.
